# life_OS ⚡

A modern, high-performance personal command center and productivity dashboard built with **React**, **Vite**, and **Tailwind CSS**.

---

## 🚀 Features

- **Personal Command Dashboard**: Real-time clock, velocity metrics, habit streaks, daily status.
- **Priority Focus Queue**: Categorized tasks (Deep Work, Strategy, Fitness, Learning) with priority tags.
- **Habit Accountability Matrix**: Daily check-offs with streak counter and completion tracking.
- **Focus Capsule (Pomodoro)**: Interactive 25m Focus / 5m Recovery timer.
- **Notes & Principles**: Quick capture for daily reflections and mental models.
- **Modern Dark UI**: Aesthetic glassmorphism, glowing accents, and responsive layout powered by Tailwind CSS.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Bundler**: [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

---

## 🏃 Getting Started

### 1. Start Development Server
```bash
npm run dev
```

The app will be available locally at `http://localhost:5173`.

### 2. Build for Production
```bash
npm run build
```

### 3. Preview Production Build
```bash
npm run preview
```
